Política de privacidade

Última atualização: 28 de outubro de 2026

O que a ferramenta acessa

A ferramenta Métricas Colosso usa as APIs do YouTube (YouTube Data API e YouTube Analytics API), com permissão somente de leitura, para consultar as estatísticas do canal do próprio dono: visualizações, tempo de exibição, inscritos e dados de retenção.

Como os dados são usados

Os dados servem só para gerar relatórios de desempenho para o dono do canal. Eles ficam armazenados no computador dele e não são vendidos, compartilhados, transferidos a terceiros nem usados para publicidade.

Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
